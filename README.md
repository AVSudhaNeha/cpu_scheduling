# CPU Scheduling Simulator

An offline, self-contained Operating Systems lab visualizer built with vanilla HTML, CSS and JavaScript.

## Features
- FCFS, SJF (non-preemptive), SRTF (preemptive SJF), Round Robin and simplified MLFQ
- Editable process list (process ID, arrival time, burst time)
- Gantt chart with clickable execution slices
- Completion time, turnaround time, waiting time, average metrics, utilization and throughput
- Plain-English operation log
- Preset scenarios
- Lab Aim & Procedure, pseudocode, illustrative C code and FAQ
- No dependencies or network requests

## Run locally
Open `index.html` in any modern browser. Internet is not required.

## Publish on GitHub
1. Create a GitHub repository (for example, `cpu-scheduling-simulator`).
2. Upload `index.html` and `README.md` (or upload the contents of this ZIP).
3. To publish as a website, open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. The site URL appears in the Pages settings.
